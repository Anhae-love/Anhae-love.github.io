# 대시보드 셋업 안내서 (1회만)

> 계정은 있고 저장소는 없는 상태 기준. 아래를 순서대로 한 번만 하면,
> 이후로는 매일 자동으로 폰에서 대시보드가 갱신된다.

프로젝트 루트 = `C:\Users\CXlab\Desktop\개인 프로젝트 야르~\인스타 프로젝트 야르~`

---

## 새로 생기는 폴더 구조 (코드/데이터 분리)

```
프로젝트루트/
├─ automation/          코드 — 기존 파이프라인 (그대로)
├─ output/              데이터 — 날짜별 결과 (그대로)
├─ state/               데이터 — 로그·이력 (그대로)
├─ docs/                ← 새로. GitHub Pages가 여기를 웹으로 발행
│   ├─ index.html       대시보드 (코드)
│   ├─ data/manifest.json   대시보드가 읽는 데이터 인덱스
│   └─ cards/<날짜>/slide_*.png   카드 사본
└─ .github/workflows/pages.yml   push되면 자동 발행
```

교수님 지적대로 **대시보드(docs/index.html)는 코드**, **manifest·cards는 데이터**. 대시보드는 output을 직접 뒤지지 않고 manifest 하나만 읽는다.

---

## STEP 1 — 파일 배치

내가 전달한 파일을 이렇게 둔다:

| 전달 파일 | 놓을 위치 |
|---|---|
| `index.html` | `docs/index.html` |
| `build_manifest.py` | `automation/build_manifest.py` |
| `pages.yml` | `.github/workflows/pages.yml` |

`docs/data/`, `docs/cards/` 폴더는 build_manifest.py가 자동으로 만든다.

---

## STEP 2 — manifest 첫 생성 (PowerShell, 루트에서)

```powershell
python automation\build_manifest.py . docs
```
`docs/data/manifest.json`과 `docs/cards/...`가 생긴다. 바로 로컬에서 열어 확인:
```powershell
start docs\index.html
```
카드가 보이면 성공. (로컬에서 파일로 열면 manifest fetch가 막힐 수 있으니, 안 보이면 STEP 4의 웹주소로 확인.)

---

## STEP 3 — 저장소 만들고 첫 push

GitHub CLI(`gh`)가 있으면 (`.copilot` 있으니 깔려있을 가능성 높음):

```powershell
cd "C:\Users\CXlab\Desktop\개인 프로젝트 야르~\인스타 프로젝트 야르~"

# .gitignore — 무거운/불필요 파일 제외
@"
__pycache__/
*.pyc
output/*/_source.*
output/*/_codex_log.txt
"@ | Out-File -Encoding utf8 .gitignore

git init
git add docs .github automation state .gitignore
git commit -m "대시보드 + 파이프라인"
gh repo create insta-hci-dashboard --private --source=. --push
```

`gh`가 없으면: github.com에서 빈 private 저장소 `insta-hci-dashboard`를 만들고,
```powershell
git init
git add docs .github automation state .gitignore
git commit -m "대시보드 + 파이프라인"
git branch -M main
git remote add origin https://github.com/<너의계정>/insta-hci-dashboard.git
git push -u origin main
```

---

## STEP 4 — Pages 켜기

1. GitHub 저장소 → Settings → Pages
2. Source: **GitHub Actions** 선택
3. 잠시 뒤 주소가 나온다: `https://<너의계정>.github.io/insta-hci-dashboard/`

**이 주소를 폰 홈화면에 추가**해두면 앱처럼 열린다.

> private 저장소도 Pages는 공개 URL이 될 수 있다. 카드에 민감정보는 없지만,
> 완전 비공개를 원하면 저장소를 두고 Pages만 조직/유료 옵션으로 제한할 수 있다. 지금은 공개 URL로 충분.

---

## STEP 5 — 파이프라인 끝에 2줄 추가

`automation\run_daily.ps1`의 **맨 끝**(카드 제작·STATUS 기록 다음)에 추가:

```powershell
# --- 대시보드 갱신 + push ---
python automation\build_manifest.py . docs
git add docs state
git commit -m "auto: $(Get-Date -Format yyyy-MM-dd) 콘텐츠"
git push
```

이제 매일 새벽 파이프라인이 끝나면 자동으로 GitHub에 올라가고, Pages가 갱신된다.
`.ps1`은 반드시 **UTF-8 BOM**으로 저장 (README의 그 규칙).
